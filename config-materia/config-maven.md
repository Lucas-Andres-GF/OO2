📋 Los datos de tu Arquetipo
Cuando hacés Ctrl + Shift + P -> Java: Create Java Project -> Maven, elegí estos valores:

Archetype: maven-archetype-quickstart (es el más liviano y limpio).

Group Id: ar.edu.unlp.info.oo2

Esto es clave en la facultad porque define la estructura de carpetas de la UNLP.

Artifact Id: ejercicioX-nombre (el nombre de tu carpeta/ejercicio).

Version: 1.0-SNAPSHOT (dejalo por defecto).
